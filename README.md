# Contact Book CLI

A command-line application to manage contacts built with Python.
Supports adding, viewing, searching, updating and deleting contacts
with data saved to a file between sessions.

## Features
- Add a new contact with name, phone and email
- View all saved contacts
- Search contacts by full or partial name
- Update an existing contact's details
- Delete a contact
- Data persists between sessions using file I/O

## How to run

1. Make sure Python 3 is installed
2. Clone the repository:
   git clone https://github.com/Elkanah490/contact-book-cli.git
3. Navigate into the folder:
   cd contact-book-cli
4. Run the program:
   python contacts.py


## Usage
'''
========== CONTACT BOOK ==========
1. Add contact
2. View all contacts
3. Search contact
4. Update contact
5. Delete contact
6. Exit
==================================
Choose an option (1-6):
'''
